## Descripción

Este repositorio contiene el desarrollo de la Prueba Práctica de la Unidad IV de la asignatura Ingeniería de Requisitos (ISR-401).

El trabajo incluye el modelado, especificación, validación, trazabilidad y gestión de requisitos del caso denominado **Sistema de Gestión de Pedidos**.

El documento principal ha sido desarrollado en LaTeX y puede reproducirse mediante compilación local con `pdflatex`.
